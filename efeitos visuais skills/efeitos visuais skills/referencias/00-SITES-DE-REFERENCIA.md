# Sites de referência (de onde vêm os efeitos desta skill)

Todos são templates Framer (exceto Bureau Nine, que é site autoral). Não têm código aberto/repositório — servem como **norte visual**. Abra-os no navegador para calibrar timing, easing e composição.

## 1. Porta Studio (Porta®) — "portastudio"
- Demo: https://porta.framer.ai/
- Estilo: minimalismo premium, dark, tipografia serifada elegante, muito espaço em branco.
- Efeitos-chave: smooth scroll pesado, texto revelado linha a linha, galeria horizontal, preloader com contador, botão magnético, reveal de imagens.

## 2. Ethan Clark
- Marketplace: https://www.framer.com/marketplace/templates/ethan-clark/ (autor: Bryan Hermoza, gratuito)
- Estilo: editorial minimalista, tipografia bold, whitespace generoso.
- Efeitos-chave: **cursor image trail** (rastro de imagens seguindo o mouse), blob/mask reveal em imagens, filtro de categorias com transições suaves.

## 3. Campione — "ovo-campione"
- Demo Framer: https://ovo-campione.framer.website/ · Versão Webflow: https://ovo-campione.webflow.io/
- Marketplace: https://www.framer.com/marketplace/templates/campione/
- Estilo: Gen-Z bold, tipografia GIGANTE, cores saturadas em blocos, energia alta.
- Efeitos-chave: tipografia oversized animada no scroll, marquees, menu fullscreen, hover com distorção.

## 4. Operator — "operator-template"
- Demo: https://operator-template.framer.website/ (autor: https://hollow0.framer.website/)
- Estilo: portfólio "playful" com grid systems rígidos e code components.
- Efeitos-chave: layout em grade com números/labels técnicos, contadores, tipografia esticada.

## 5. Avyron — "avyron-pro"
- Demo: https://avyron-pro.framer.website/
- Estilo: portfólio criativo moderno, limpo com momentos de motion.
- Efeitos-chave: marquee, botão magnético, cards com hover elaborado.

## 6. Bureau Nine
- Site: https://bureaunine.com/ (Bureau Nine Ltd, Inglaterra — site autoral, não é template)
- Estilo: dark total (#070708), estética "dossiê/terminal": seções numeradas em romano (SECTION I · II · III), labels tipo NODE/SESSION/CONTACT, monospace, mistério.
- Efeitos-chave: ver `efeitos/13-estetica-terminal-dossie.md`.
